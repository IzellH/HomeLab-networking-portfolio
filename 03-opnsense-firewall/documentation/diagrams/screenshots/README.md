OPNsense Lab — Screenshots and Evidence

Purpose

This directory contains sanitized screenshots documenting the deployment, configuration, and validation of the OPNsense firewall lab.

Screenshots provide visual evidence of completed implementation steps and testing results.

4. Firewall Administration

- Firewall rules.
- NAT configuration.
- Firewall log entries.
- Network isolation test results.

Screenshot Guidelines

Before uploading screenshots to this public repository:

- Hide real private IP addresses.
- Hide public IP addresses.
- Remove usernames and identifying hostnames where appropriate.
- Never expose passwords, API keys, authentication tokens, or secret keys.
- Avoid displaying Tailscale device information or authentication details.
- Use sanitized examples when documenting network configurations.
