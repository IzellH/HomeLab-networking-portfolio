# Projects and Labs

Hands-on networking, infrastructure, and systems administration projects completed or planned in the homelab.

## Completed Projects

### Proxmox Virtualization
- Deployed Proxmox VE on physical hardware.
- Created and managed virtual machines.
- Configured virtual network bridges.

### OPNsense Firewall Lab
- Deployed OPNsense as a virtual firewall.
- Configured WAN and LAN interfaces.
- Established an isolated lab network.
- Verified gateway connectivity and outbound IP routing.

### Homelab Storage
- Configured shared storage on a dedicated hard drive.
- Set up NFS exports.
- Tested file creation and deletion permissions.

### Docker Services
- Deployed containerized applications.
- Used Portainer to manage Docker stacks.
- Configured media and home server applications.
